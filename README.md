# Botão Marreco

App estático responsivo com HTML e Tailwind CSS. Escolha um animal no topo e aperte o botão central para tocar seu som. Cada clique interrompe a reprodução atual e reinicia o áudio do começo.

## Rodar localmente

Abra `index.html` no navegador ou execute um servidor estático na pasta.

## Publicar na Vercel

Importe esta pasta como um novo projeto. Não é necessário configurar framework, comando de build ou pasta de saída.

## Imagens

As fotos de marreco, sapo, vaca, porco e galo são imagens de domínio público obtidas no PublicDomainPictures.net. A imagem da cabra foi extraída do vídeo fornecido com o projeto.
