# Botão Marreco

App estático responsivo com HTML e Tailwind CSS. Cada clique cria uma nova instância de áudio, permitindo reproduções simultâneas.

## Rodar localmente

Abra `index.html` no navegador ou execute um servidor estático na pasta.

## Publicar na Vercel

Importe esta pasta como um novo projeto. Não é necessário configurar framework, comando de build ou pasta de saída.
